# KidsControlPC — Child Agent

Фоновый агент, который устанавливается на **ПК ребёнка** и применяет правила блокировки из Firebase.

## Что умеет

- 🔒 **Блокировка сайтов** — записывает домены в `C:\Windows\System32\drivers\etc\hosts`
- 🚫 **Блокировка программ** — завершает процессы заблокированных приложений каждые 5 секунд
- 💓 **Heartbeat** — отправляет статус "Онлайн" родителю каждые 30 секунд
- 🚨 **Тревога** — при закрытии агента родитель получает уведомление в приложении
- ⏱️ **Умные режимы** — поддерживает постоянные/по таймеру/по расписанию/по дате правила

## Установка на ПК ребёнка

### Требования
- Windows 10 / 11
- Node.js 18+ (или будет bundled в итоговом .exe)
- **Запуск от имени Администратора** (нужен для изменения hosts-файла)

### Шаги

1. Скопируйте папку `agent/` на ПК ребёнка
2. Откройте PowerShell **от имени Администратора**
3. Перейдите в папку: `cd C:\path\to\agent`
4. Установите зависимости: `npm install`
5. Запустите: `npm start`
6. При первом запуске введите код из родительского приложения

## Запуск как Windows Service

Агент можно установить как фоновую службу Windows (Service), которая запускается автоматически при загрузке системы (до входа пользователя).

### Установка службы
1. Откройте консоль (PowerShell или CMD) **от имени Администратора**.
2. Перейдите в каталог агента и выполните:
   ```bash
   npm run service:install
   ```
   *Служба `KidsControlPCAgent` будет зарегистрирована в системе и запущена.*

### Удаление службы
1. Откройте консоль **от имени Администратора**.
2. Выполните:
   ```bash
   npm run service:uninstall
   ```
   *Служба будет остановлена и полностью удалена из системы.*
