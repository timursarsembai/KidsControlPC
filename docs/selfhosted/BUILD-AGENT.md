# Сборка агента на чистом Windows-ПК

Агент собирается только на Windows: половина его частей — это программы на C#,
которые компилируются компилятором из состава Windows, а установщик собирает
NSIS. На сервере (Linux) сборка невозможна в принципе.

Проверено по содержимому `agent/build_installer.js`, а не по памяти.

## 1. Что поставить

| Что | Зачем | Откуда |
|---|---|---|
| **Node.js LTS** | esbuild собирает бандл, pkg превращает его в `agent.exe` | nodejs.org, установщик `.msi` |
| **Git для Windows** | забрать репозиторий | git-scm.com |
| **NSIS** | собрать `KidsControlAgent_Setup.exe` | nsis.sourceforge.io |

Если `npx pkg` споткнётся на свежей Node (он старый и не всегда дружит с
новыми версиями) — поставьте Node 20 LTS, на ней сборка заведомо проходит.

**Компилятор C# ставить не нужно.** Скрипт зовёт `csc.exe` по пути
`C:\Windows\Microsoft.NET\Framework\v4.0.30319\csc.exe` — он есть в любой
Windows из коробки.

**Отдельного .NET SDK тоже обычно не нужно.** Виджетам требуется
`System.Speech.dll` (озвучка напоминаний); скрипт ищет её сначала среди
targeting packs, потом в GAC — а в GAC она лежит в любой Windows. Если сборка
всё же скажет `System.Speech.dll not found`, поставьте
[.NET Framework 4.x Developer Pack](https://dotnet.microsoft.com/download/dotnet-framework).

**Интернет нужен:** во время сборки скачиваются WebView2 SDK (с nuget.org) и
`WinSW.exe` (с github.com) — это оболочка службы Windows.

## 2. Забрать код

```powershell
git clone https://github.com/timursarsembai/KidsControlPC
cd KidsControlPC
git checkout selfhosted
```

Ветка важна: в `master` лежит версия для Firebase.

## 3. Установить зависимости

```powershell
cd agent
npm install
```

Ставится именно в `agent`, а не в корне: агент не входит в рабочее
пространство npm корневого проекта и держит зависимости у себя.

## 4. Собрать

```powershell
npm run build:selfhosted
```

Пять шагов: бандл → `agent.exe` → виджеты на C# → WebView2 и WinSW →
установщик. На выходе:

```
agent\dist\KidsControlAgent_Setup.exe
```

Обычная `npm run build` соберёт агента **для Firebase** — так и задумано.
Разница между сборками ровно одна: константа, вшитая в исполняемый файл.

Адрес сервера по умолчанию — `https://api.kidscontrol.kz`. Если нужен другой,
задайте перед сборкой:

```powershell
$env:KIDSCONTROL_API_BASE_URL = "https://api.example.kz"
npm run build:selfhosted
```

## 5. Поставить на детский ПК

Скопировать `KidsControlAgent_Setup.exe` на машину и запустить **от имени
администратора** — он ставит службу Windows.

При первом запуске агент попросит код привязки: в панели
Настройки → Устройства → «Сгенерировать код». Код живёт 15 минут.

## Чего делать нельзя

**Не публикуйте эту сборку в GitHub Releases того же репозитория.** Агенты на
детских ПК обновляются оттуда сами и не различают сборки: они скачают эту и
переедут на сервер, с которым никогда не были связаны, — то есть останутся
без правил, тихо и у всех сразу. Ставить только вручную.

## Если что-то пошло не так

**`File: failed opening file .\WinSW.exe` на шаге 5** — старая версия
сборочного скрипта: он открывал файл до того, как выяснял, что ответ сервера —
редирект, и незакрытый дескриптор держал файл заблокированным. Починено
24.08.2026; сделайте `git pull` и удалите `agent\dist\WinSW.exe`, если он
остался нулевого размера.

**`makensis` не найден** — NSIS не установлен или установлен не в
`Program Files`. Скрипт ищет его в обычных местах, затем в `PATH`; можно
просто добавить каталог NSIS в `PATH`.

**Антивирус ругается на `agent.exe`** — обычное дело для программ, собранных
`pkg`: внутри лежит распакованный интерпретатор Node. Понадобится исключение,
а в перспективе — подпись исполняемого файла сертификатом.

**`Cannot find module '@kidscontrol/shared/...'`** — `npm install` запускали
не в `agent`, либо каталог `shared` отсутствует (репозиторий забрали не
целиком).

## Что нельзя проверить с сервера

На Windows-машине живут вещи, которых нет ни в одном контейнере: служба,
блокировка процессов, виджет поверх экрана, рантайм `pkg`. Сетевой слой агента
и его поведение при потере связи проверены на сервере отдельно, всё
остальное — только здесь.
