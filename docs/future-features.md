# Будущие фичи KidsControlPC

Функции, запланированные к реализации. Текущий MVP полностью готов — эти фичи идут следующим этапом.

---

## Безопасность агента

### Anti-Tamper (Защита от отключения)

**Проблема:** Подросток может остановить или удалить агента через Диспетчер задач, `services.msc` или «Программы и компоненты».

**Вариант A — Watchdog-служба** _(реалистично, средняя сложность)_
- Вторая лёгкая служба Windows следит за основной (`KidsControlPCAgent`) и перезапускает её при падении.
- Основная служба следит за Watchdog — взаимный мониторинг.
- Обе службы настроены на `Start=Automatic`, `FailureActions=restart`.
- При попытке остановить одну — вторая немедленно её поднимает.

**Вариант B — Kernel-mode driver** _(сложно, максимальная защита)_
- Драйвер режима ядра (C/C++, WDK) защищает процесс от `TerminateProcess`.
- Требует подписи Microsoft (EV certificate + WHQL или attestation signing).
- Папка установки помечается как защищённая через DACL — рядовой пользователь не может удалить файлы.
- Нельзя остановить никакими пользовательскими средствами.

**Рекомендация:** Начать с Watchdog-службы (вариант A). Даёт 90% защиты при разумных затратах. Kernel-driver — в Premium-tier.

## Бесплатный тариф (Free Tier)

### SafeSearch
- Агент подменяет IP Google, YouTube, Bing в `hosts` на официальные SafeSearch-сервера.
- Блокирует взрослый контент в поиске без блокировки всего интернета.
- Реализация: список хостов → резолвим SafeSearch IP → пишем в `C:\Windows\System32\drivers\etc\hosts`.

### Ежедневный лимит времени (Screen Time)
- Родитель задаёт общий лимит использования ПК в день (например, 2 часа).
- Агент считает активное время сессии, при истечении — блокирует экран или выключает ПК.
- Счётчик сбрасывается в полночь.

### Всплывающие уведомления ребёнку
- Родитель отправляет короткое сообщение прямо на экран ребёнка («Пора ужинать!»).
- Агент показывает системное уведомление или модальное окно поверх всех приложений.
- Реализация: команда через Firestore → агент → Windows Toast Notification или кастомное окно.

## Платная подписка (Premium Tier)

### Трансляция экрана в реальном времени (Live View)
- Родитель подключается к экрану детского ПК в реальном времени из веб-приложения.
- Технология: WebRTC (peer-to-peer через STUN/TURN серверы).
- Агент захватывает экран и стримит, веб-приложение отображает поток.

### Фильтрация по категориям (Category Web Filter)
- Вместо ручного ввода доменов — тумблеры: «Соцсети», «Игры», «Порнография».
- Реализация: перенаправление DNS на семейные серверы (Cloudflare Family `1.1.1.3` / Яндекс.DNS).
- Агент меняет DNS-сервер сетевого адаптера или использует локальный DNS-резолвер.

### Подробная аналитика и AI-отчёты
- Графики: Учёба vs Игры по дням/неделям.
- Еженедельный email-отчёт с AI-анализом (Claude API): динамика, аномалии, рекомендации.
- Пример: «На этой неделе ребёнок провёл на 30% больше времени в играх. Замечены попытки открыть заблокированные сайты.»

### Расширенное управление питанием
- Кнопка «Заблокировать немедленно» — накладывает заглушку поверх всех окон, нельзя закрыть.
- Удалённая перезагрузка / выключение ПК (уже частично есть, расширить UI).

## Инфраструктура

### Переезд SMTP с Gmail на Resend
- Текущий `smtp.gmail.com` / `kidscontrolpc@gmail.com` → письма попадают в спам.
- Resend.com: бесплатно 3000 писем/месяц, автоматический SPF/DKIM, высокая доставляемость.
- Изменения: только 4 переменные в `.env`, код не меняется.
- После подключения домена — слать с `noreply@kidscontrolpc.com`.
