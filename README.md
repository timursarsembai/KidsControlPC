# KidsControlPC 🛡️

Мощная, современная и безопасная платформа для родительского контроля. 
Проект состоит из **красивого веб-приложения** для родителя (доступно с любого устройства) и **невидимого фонового агента** для компьютера ребенка (Windows).

## Возможности ✨

* **🌐 Блокировка сайтов (Web Filter)**: Полная блокировка доступа к нежелательным ресурсам (через системный файл `hosts`).
* **🚫 Блокировка программ (App Blocker)**: Принудительное закрытие запрещенных игр и приложений.
* **🔒 Блокировка экрана (Screen Lock)**: Удаленная блокировка компьютера полноэкранной заставкой с кастомным изображением/цветом, текстом и разблокировкой по ПИН-коду.
* **📢 Напоминания (Reminders)**: Отправка настраиваемых текстовых и голосовых сообщений (Text-to-Speech) на экран ребенка. Поддержка гибких расписаний и одноразовых таймеров.
* **⚡ Управление устройством (Power Management)**: Возможность удаленно выключить или перезагрузить компьютер ребенка в один клик.
* **⏱️ Помодоро-таймер**: Чередование учебы и отдыха по заданным интервалам времени (например, 45 минут учебы, 15 минут перерыв).
* **👮 Система штрафов и защиты**: При многократных попытках ребенка открыть заблокированную программу срабатывает сирена с голосовым предупреждением, а экран блокируется. После 5-й попытки ПК выключается автоматически.
* **🗓️ Гибкие правила контроля**: 
  * **Постоянная**: Всегда активна.
  * **По таймеру**: Блокировка на заданное время (например, на 2 часа).
  * **По расписанию**: В определенные дни недели и промежутки времени.
  * **По дате**: Конкретная дата и время.
  * **Ежемесячно**: Повторение в определенные числа месяца.
* **🚨 Живые Уведомления**: Родитель получает мгновенные уведомления о событиях на ПК ребенка (закрыта программа, прочитано напоминание, компьютер включен/выключен).
* **🔄 Автообновление агента**: Агент на ПК ребенка обновляется абсолютно прозрачно и автоматически (в фоне), не требуя вмешательства.
* **📊 Онлайн статус**: Вы всегда видите в реальном времени, в сети ли компьютер ребенка и какая версия агента на нем установлена.

## Структура проекта 📂

- `web/` — Исходный код родительского веб-приложения (React + Vite, хостинг на Firebase).
- `agent/` — Исходный код фоновой службы (Windows Service) для ПК ребенка (Node.js + C# виджеты).

## Установка и Использование 🚀

### 1. Веб-панель родителя
Вам больше не нужно ничего скачивать! 
Просто зайдите на **[https://kidscontrolpc.web.app](https://kidscontrolpc.web.app)** с любого телефона, планшета или компьютера.
- Войдите через Google или Email.
- Зайдите в **Устройства** -> **Добавить устройство** и сгенерируйте 6-значный код привязки.

### 2. Установка детского агента
Скачайте готовый `.exe` установщик агента в разделе **[Releases](../../releases/latest)**.
- Запустите `KidsControlAgent_Setup.exe` на компьютере ребёнка. Установщик запросит права Администратора.
- Агент автоматически зарегистрируется как системная Windows-служба.
- После установки откроется черное окно — введите сгенерированный 6-значный PIN-код.
- Готово! ПК привязан, блокировки и расписания начнут действовать мгновенно. Агент будет сам скачивать новые версии с GitHub и обновляться незаметно для ребенка.
