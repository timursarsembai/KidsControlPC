# KidsControlPC 🛡️

Мощное, современное и безопасное приложение (Windows) для родительского контроля. 
Проект состоит из **красивой панели управления** для родителя и **невидимого фонового агента** для компьютера ребенка.

## Возможности ✨

* **🌐 Блокировка сайтов (Web Filter)**: Полная блокировка доступа к нежелательным ресурсам (через системный файл `hosts`).
* **🚫 Блокировка программ (App Blocker)**: Принудительное закрытие запрещенных игр и приложений.
* **⏱️ Помодоро-таймер (Интервалы)**: Чередование учебы и отдыха по заданным интервалам времени (например, 45 минут учебы, 15 минут перерыв).
* **🗓️ Гибкие правила контроля**: 
  * **Постоянная**: Всегда активна.
  * **По таймеру**: Блокировка на заданное время (например, на 2 часа).
  * **По расписанию**: В определенные дни недели и промежутки времени.
  * **По дате**: Конкретная дата и время.
* **🚨 Уведомления и защита**: Если ребенок попытается закрыть Агента, родитель получит тревожное уведомление.
* **📊 Онлайн статус**: Вы всегда видите в реальном времени, включен ли компьютер ребенка.

## Структура проекта 📂

- `src/` — Исходный код родительского Electron/React приложения.
- `agent/` — Исходный код фоновой службы (Windows Service) для ПК ребенка.

## Установка и Использование 🚀

Скачайте готовые `.exe` установщики в разделе **[Releases](../../releases)**!

### 1. Установка родительского приложения
Запустите `KidsControlPC_Setup.exe` на своём компьютере. 
- Пройдите авторизацию (Google / Email).
- Зайдите в меню **Устройства** -> **Добавить устройство** и сгенерируйте 6-значный код привязки.

### 2. Установка детского агента
Запустите `KidsControlAgent_Setup.exe` на компьютере ребёнка.
- Установщик запросит права Администратора.
- Агент автоматически зарегистрируется как системная Windows-служба.
- После установки откроется черное окно — введите сгенерированный 6-значный PIN-код.
- Готово! ПК привязан, блокировки начнут действовать мгновенно.
